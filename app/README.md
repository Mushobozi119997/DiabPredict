# DiabPredict

Application web de prédiction du diabète développée avec Flask et Machine Learning.

## Description

DiabPredict permet d'estimer le risque de diabète à partir de données médicales saisies par l'utilisateur. Le modèle de Machine Learning a été entraîné sur un jeu de données médical puis intégré dans une application web Flask.

## Fonctionnalités

* Saisie des données médicales via une interface web.
* Prédiction automatique du risque de diabète.
* Affichage du résultat en temps réel.
* Historique des prédictions enregistré dans une base SQLite.
* Interface simple et intuitive.

## Technologies utilisées

* Python
* Flask
* Scikit-learn
* NumPy
* Pandas
* SQLite
* HTML/CSS/Bootstrap

## Installation

Cloner le dépôt :

git clone https://github.com/Mushobozi119997/DiabPredict.git

Accéder au projet :

cd DiabPredict

Installer les dépendances :

pip install -r requirements.txt

Lancer l'application :

python app.py

Puis ouvrir dans le navigateur :

http://127.0.0.1:5000

## Modèle de Machine Learning

Le modèle est entraîné pour prédire la présence ou l'absence du diabète à partir de plusieurs variables médicales.
